# Көпір — лендинг (React + Vite + TS)

Мост между вашим опытом и дефицитной профессией. ИИ-навигатор рынка труда.

## Запуск локально

Нужен установленный [Node.js](https://nodejs.org) (18+).

```bash
# 1. распакуйте архив и перейдите в папку
cd kopir-react

# 2. установите зависимости
npm install

# 3. запустите dev-сервер
npm run dev
```

Откроется на **http://localhost:5173** (Vite откроет вкладку браузера автоматически).

## Структура

```
kopir-react/
  src/
    components/
      Header.tsx      — шапка + мобильное меню
      Hero.tsx         — иллюстрация моста + имя/слоган
      Vacancies.tsx     — сетка вакансий (аналог "мои работы")
      HowItWorks.tsx    — 3 шага на волнистой линии (аналог "услуги")
      About.tsx         — о проекте
      Footer.tsx        — подвал с QR и контактами
    index.css           — все стили, палитра в :root
    App.tsx
    main.tsx
  index.html
  package.json
```

## Палитра

| Переменная       | Hex       | Использование                    |
|------------------|-----------|-----------------------------------|
| `--cream`        | `#F6F1E6` | фон                                |
| `--cream-warm`   | `#EBE0C9` | карточки, подложки                |
| `--tan`          | `#D9C6A0` | фон секции "как это работает"     |
| `--olive-deep`   | `#4F5530` | заголовки, кнопки, футер          |

| `--ink`          | `#33291E` | текст                              |
